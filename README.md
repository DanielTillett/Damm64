# damm64: base64url Damm check digits

The [Damm algorithm](https://en.wikipedia.org/wiki/Damm_algorithm) is a check digit algorithm that detects every single-character error and every adjacent transposition. Prepending leading zeros does not change the check digit.

**damm64** applies it to the base64url alphabet ([RFC 4648 §5](https://www.rfc-editor.org/rfc/rfc4648#section-5)), with matching implementations in C, PHP and JavaScript. Each one is a library plus a command-line tool, and all three give identical output.

```
ABCDEFGHIJKLMNOPQRSTUVWXYZabcdefghijklmnopqrstuvwxyz0123456789-_
```

Base64 zero is `A`. Input is **case-sensitive**.

| Implementation | Location | Requires |
| --- | --- | --- |
| C | [`include/`](include), [`src/`](src) | C99 compiler, CMake 3.16+ |
| PHP | [`php/`](php) | PHP 7.4+ |
| JavaScript | [`js/`](js) | Node.js 20+, or any modern browser |

## Which version should I use?

| | [damm32](https://github.com/DanielTillett/Damm32) | damm64 | [damm95](https://github.com/DanielTillett/Damm95) |
| --- | --- | --- | --- |
| Alphabet | Lowercase letters and digits without look-alikes, plus `*` | base64url | All printable ASCII |
| Bits per character | 5 | 6 | ~6.6 |
| Case | Insensitive | Sensitive | Sensitive |
| Best for | Codes people read and type | IDs and tokens that are copied, or used in URLs | Compact machine-to-machine strings |

damm64 still detects every single-character error, including a wrong-case letter or `0`/`O`. But base64 contains easily confused characters, so people will make those errors far more often than with damm32. Use it for codes that are copied and pasted rather than typed. Strip any `=` padding before checking base64 data.

## How it works

The 64 × 64 quasigroup is not stored as a table. It is computed from one formula:

> x ∗ y = 2 · (x ⊕ y) in GF(64), with the primitive polynomial x⁶ + x + 1

XOR puts zeros on the diagonal, so a correct code ends in `A`. Because 2 and 2² + 2 are both non-zero in the field, the operation is totally anti-symmetric, so every adjacent transposition is detected. The base32 table in damm32 is the same construction with x⁵ + x + 1. The tests check every property exhaustively, all 64³ combinations, in all three languages.

```c
#include "damm64.h"

char digit = damm64_check_digit("Hello");  /* 'p', or DAMM64_INVALID ('\0') */
bool ok    = damm64_is_valid("Hellop");    /* true */
int value  = damm64_value('H');            /* 0-63, or -1 if not in the alphabet */
```

## Command-line usage

All three implementations share the same interface:

```
damm64 [-a | -c] [code ...]

  -a, --append   print each code with its check digit appended
  -c, --check    print nothing; exit 0 only if every code is valid
  -h, --help     show this help
  -V, --version  show the version
```

With no codes on the command line, codes are read from standard input, **one per line**. Because `-` is part of the alphabet, put `--` before a code that starts with `-`. Exit status is 0 on success, 1 if a code is invalid or contains a character outside the alphabet, and 2 on a usage error.

```
$ damm64 Hello
Base64 Number: Hello
Base64 Check Digit: p
Error Check: 0

$ damm64 -a Hello
Hellop

$ damm64 -c Hellop && echo valid
valid
```

Generate a random 22-character token (21 random characters plus the check digit):

```bash
openssl rand -base64 32 | tr '+/' '-_' | tr -d '=\n' | head -c21 | damm64 -a
```

## PHP

```bash
composer require danieltillett/damm64
```

```php
use Damm64\Damm64;

Damm64::checkDigit('Hello');  // 'p', or Damm64::INVALID (null)
Damm64::isValid('Hellop');    // true
Damm64::value('H');           // 0-63, or -1 if not in the alphabet
```

The command-line tool is installed as `vendor/bin/damm64`. Without Composer, `require` [`php/src/Damm64.php`](php/src/Damm64.php) directly. Run the tests with `php php/tests/Damm64Test.php`.

## JavaScript

```bash
npm install damm64
```

```js
import { checkDigit, isValid, value, INVALID } from 'damm64';

checkDigit('Hello');  // 'p', or INVALID (null)
isValid('Hellop');    // true
value('H');           // 0-63, or -1 if not in the alphabet
```

The package is a dependency-free ES module with TypeScript declarations, and includes the `damm64` command (`npx damm64`). Run the tests with `npm test --prefix js`.

## Testing

[`tests/vectors.txt`](tests/vectors.txt) holds every one- and two-character code plus random longer and invalid codes, with their check digits, generated by an independent Python reference implementation. Each line is `code<TAB>digit`; an empty digit means invalid, and lines without a tab are comments. The C, PHP and JavaScript suites all check against it, and CI runs them on Linux, macOS and Windows (C), PHP 7.4–8.4 and Node.js 20–24.
